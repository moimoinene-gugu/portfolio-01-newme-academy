# NewMe Academy Landing Page

A responsive landing page designed for **NewMe Academy**, a fictional life-design coaching program for adults in their 50s.

---

# 🇯🇵 日本語

## プロジェクト概要

この作品は、現代を生きる50代の方々の気持ちや悩みに寄り添い、「新しい人生に挑戦したい」という想いをテーマに制作した架空のランディングページです。

デザインの美しさだけでなく、人生の新たな一歩を踏み出すきっかけとなるよう、「安心感」「信頼感」「前向きな気持ち」を伝えることを意識しました。

また、レスポンシブ対応やアニメーションなど、実際のWeb制作案件を想定した制作フローで取り組み、デザインからコーディングまで一貫して制作しています。

# 🇺🇸 English

## Project Overview

This project is a fictional landing page inspired by the thoughts and aspirations of people in their 50s who are ready to embrace a new chapter in life.

Rather than focusing only on visual design, I aimed to create a user experience that conveys trust, reassurance, and the confidence to take the first step toward positive change.

The project was developed using a real-world workflow, including responsive design, interactive animations, and front-end implementation from design to code.
